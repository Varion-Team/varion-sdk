# Varion SDK

CLI and tooling for making game modes on [Varion](https://varionmp.net).

```sh
npm i -g git+https://github.com/Varion-Team/varion-sdk.git
varion new my-mode
cd my-mode
npm run dev
```

Needs Node.js 22.12+. Documentation: [docs.varionmp.net](https://docs.varionmp.net).
